# Readiness Reports (Schema + Tools)

This document defines the readiness report artifacts and the index schema used by tooling.

## Artifacts

Generated by `scripts/readiness_report.sh` and the pipeline:

- `build/reports/readiness_report_*.md` — per-run report (markdown).
- `build/reports/readiness_report_*.json` — per-run report (JSON).
- `build/reports/readiness_latest.md` — latest report.
- `build/reports/readiness_latest.json` — latest JSON report.
- `build/reports/readiness_latest.meta` — latest report pointers.

Index + derived outputs:

- `build/reports/readiness_index.jsonl` — append-only index (JSONL).
- `build/reports/readiness_summary.md` — summary table from index.
- `build/reports/readiness_summary.html` — HTML summary.
- `build/reports/readiness_dashboard.html` — HTML dashboard.
- `build/reports/readiness_index_stats.md` — stats from index.
- `build/reports/readiness_index_stats.json` — stats (JSON).
- `build/reports/readiness_index.csv` — CSV export.
- `build/reports/readiness_rollup.md` — daily rollup.
- `build/reports/readiness_rollup.json` — daily rollup (JSON).

## Index schema (JSONL)

Each line is a JSON object with required fields:

- `timestamp` (string): `YYYYMMDD_HHMMSS`
- `profile` (string): `minimal|quick|full|...`
- `overall` (string): `PASS|FAIL`
- `dry_run` (bool)
- `total_duration_sec` (int)
- `git_rev` (string)
- `git_dirty` (string): `clean|dirty`
- `report` (string): markdown path
- `json` (string): JSON report path
- `log_dir` (string): log directory
- `tag` (string, optional): e.g. `nightly`, `ci`

Schema file: `docs/readiness_index.schema.json`.

## Tools

Index tools:

- `make readiness-report-index` — append to index (via report tool).
- `make readiness-report-index-stats` — stats (md + json).
- `make readiness-report-index-prune` — keep last N entries.
- `make readiness-report-index-csv` — CSV export.
- `make readiness-report-index-query` — filter index by fields/time.
- `make readiness-report-index-rollup` — daily rollup.
- `make readiness-report-index-merge` — merge multiple index files.
- `make readiness-report-index-compact` — dedupe + keep last N.
- `make readiness-report-index-diff` — compare two index files.

Pipeline:

- `make readiness-pipeline` — report + summary + stats + rollup + validate (CSV optional).

Smoke verifiers:

- `make verify-readiness-report`
- `make verify-readiness-report-summary`
- `make verify-readiness-report-index-tools`
- `make verify-readiness-report-index-csv`
- `make verify-readiness-report-index-query-rollup`
- `make verify-readiness-report-index-merge-compact`
- `make verify-readiness-pipeline`
