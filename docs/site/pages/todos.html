Format

  • ID: stable short identifier.
  • Priority: P0 highest, then P1, P2, P3.
  • Weight: W5 highest leverage, then W4, W3, W2, W1.
  • Status: todo, doing, blocked, or done.
  • Gate: verification command that must pass before marking done.
