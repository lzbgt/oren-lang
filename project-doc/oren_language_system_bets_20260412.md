# Language/System Bets Snapshot

**Updated:** 2026-05-26

Current bets that remain true:

- deterministic execution and capability-gated effects are core product directions;
- the toolchain keeps C, native, and AVM backends alive for different deployment needs;
- fixtures are the executable spec while ABI/opcodes are rolling;
- AVM is the sandboxed bytecode path but is not production-ready for iOS embedding yet;
- concise docs are now preferred over accumulating rolling history.

Current implementation details live in `docs/LANGUAGE.md`, `docs/DESIGN.md`, and
`docs/STATUS.md`.
