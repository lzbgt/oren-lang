# Positioning Snapshot

**Updated:** 2026-05-26

Oren should not be positioned as a clone or direct replacement for one mainstream
language. The current distinctive direction is:

- self-hosted compiler with C, native, and AVM bytecode outputs;
- deterministic execution and capability-gated effects;
- explicit runtime/effect ledgers;
- sandbox-oriented AVM path for future compiler-in-AVM workflows.

Public copy is guarded separately by `make verify-public-readme-positioning`.
