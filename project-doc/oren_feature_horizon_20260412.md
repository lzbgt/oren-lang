# Feature Horizon Snapshot

**Updated:** 2026-05-26

The feature horizon is now tracked directly in `docs/BLEEDING_EDGE_TASKS.md`. Retained
current priorities:

- runtime robustness and allocator/GC correctness;
- native performance parity on hot loops and allocation-heavy workloads;
- tagged-value convergence across backends;
- AVM iOS embeddability and release packaging;
- AVM full-suite manifest runner;
- compiler-in-AVM packaging and default release gate;
- platform breadth for x64/Linux/Windows.
